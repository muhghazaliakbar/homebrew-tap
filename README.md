# muhghazaliakbar/tap

Homebrew casks for my macOS apps.

| App | What it does | Install |
|---|---|---|
| [Digby](https://github.com/muhghazaliakbar/digby) | Native GUI for the [Mole](https://github.com/tw93/mole) disk cleanup CLI | `brew install --cask muhghazaliakbar/tap/digby` |
| [Downsweep](https://github.com/muhghazaliakbar/downsweep) | Menu bar app that keeps your Downloads folder tidy | `brew install --cask muhghazaliakbar/tap/downsweep` |

Casks here are updated automatically by each app's release workflow.
